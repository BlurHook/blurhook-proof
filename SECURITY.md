# Security reporting

Report suspected security issues through this repository's Security → Report a vulnerability private reporting facility. The owner enables that facility on publication. Do not post exploit details, private keys, note secrets or account credentials in a public issue. Do not test with user funds.

These developer packages have not had an independent security audit. Tests cover documented local behavior, not every token, route, RPC or adversarial deployment. The custom BlurHook privacy adapter's audit status is documented in blurhook-contracts. No bounty or response-time commitment is promised.

# Security reporting

Report suspected security issues through this repository's Security → Report a vulnerability private reporting facility. Do not post exploit details, private keys, note secrets or account credentials in a public issue. Do not test with user funds.

These developer packages have not had an independent security audit. Tests cover documented local behavior, not every token, route, RPC or adversarial deployment. The custom OpalHook privacy adapter has yet to receive an independent audit. No bounty or response-time commitment is promised.
